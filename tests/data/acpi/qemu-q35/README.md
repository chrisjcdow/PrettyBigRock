# QEMU's ACPI tables: `q35`

QEMU's `q35` machine (x86-64), as the x86-64 UEFI boot test starts it: OVMF, four cores, two serial ports, the standard VGA, virtio disks and a random number generator.

Saved by `cargo xtask acpidump` (docs/design/0028-acpi.md, section 10), which boots the stick
image with `acpidump` on the kernel's command line and writes back what the kernel prints.
QEMU 10.2.1 (Ubuntu's), 28 November 2026. QEMU writes its tables to fit the machine it is
given, so a different command line (another serial port, more cores) would give different
ones; run the command again after changing how the boot tests start QEMU, and check that
`lib/aml`'s tests still pass.

They are the test data for the AML interpreter (`lib/aml`), beside Roxy's
(`../roxy-h61mx/`). QEMU's tables are generated by QEMU's own code, which is under the GPL,
version 2 or later.
